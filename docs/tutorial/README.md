## 快速开始

!!! info "快速安装"
    推荐使用 [GLM Coding Plan](01-basics/01-getting-started.md) 作为模型服务。

    ```bash
    # 1. 安装 Claude Code
    curl -fsSL https://claude.ai/install.sh | bash

    # 2. 使用自动化配置脚本
    npx @z_ai/coding-helper

    # 3. 启动
    claude
    ```

    详见：[环境搭建完整指南](01-basics/01-getting-started.md)
