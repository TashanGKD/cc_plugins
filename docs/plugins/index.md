# 插件文档

他山团队 (Tashan) 为 Claude Code 开发的专业插件集合，专注于学术研究工作流的自动化与优化。

## 插件列表

### [Scispark 研究工作流](scispark.md)

基于 Scispark 方法的7阶段结构化研究想法生成系统。

**核心功能：**
- 事实提取 → 假设生成 → 初始想法 → 技术优化 → MoA优化 → 人机协作
- 内置专家系统评审机制
- 文献追踪与管理
- 支持幻灯片生成

**适用场景：** 文献综述、研究设计、论文撰写

---

### [Manim Creator](manim-creator.md)

数学动画制作插件，基于 Manim 库生成高质量数学可视化内容。

**核心功能：**
- 自然语言描述生成动画代码
- 支持常见数学可视化场景
- 一键渲染导出视频

**适用场景：** 教学视频、学术展示、概念演示

---

## 快速开始

1. 确保已安装 [Claude Code](../tutorial/01-basics/01-getting-started.md)
2. 根据插件文档配置依赖
3. 在 Claude Code 中使用 `/命令名` 调用插件功能
