## 快速开始

```bash
# 1. 安装 Claude Code
curl -fsSL https://claude.ai/install.sh | bash

# 2. 配置 GLM 密钥
export ANTHROPIC_API_KEY="your-api-key-here"

# 3. 启动
claude
```
